# 📚 Biblioteca App

Um aplicativo mobile desenvolvido em **React Native (Expo)** para o gerenciamento de uma biblioteca pessoal. O projeto permite o cadastro, listagem, edição e remoção de livros, com persistência de dados local através do `AsyncStorage`.

## Tecnologias Usadas:

*   React Native
*   Expo
*   React Navigation
*   AsyncStorage
*   Context API

## ✨ Funcionalidades

*   Listagem de Livros
*   Cadastro e Edição
*   Detalhes do Livro
*   Remoção
*   Persistência Local
